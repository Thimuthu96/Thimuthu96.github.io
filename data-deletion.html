Data Deletion Instructions

CryptoFX Daily Publisher is a private tool used only by the owner of the CryptoFX Daily Facebook Page to publish that Page's own posts and Reels through the Facebook Graph API. It is not available to the public and does not let anyone else log in.

What data the tool has

The tool does not collect, read or store personal data of Facebook users. It only uses the Page owner's own Page access token, kept as an encrypted secret in the owner's private GitHub repository, to publish posts. The repository logs the IDs, titles and dates of the posts the tool published.

How to request deletion

If you believe the tool holds any data about you and want it deleted, email everyday.science1100@gmail.com with the subject "Data deletion request". We will reply within 30 days and confirm once any data has been deleted.

Removing the app's access

A Facebook user who has used the app can remove it at any time: Facebook → Settings & privacy → Settings → Apps and websites → select the app → Remove.
